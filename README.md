# Job Heroes – Next.js Version

## Deploy auf Vercel (einmalig)

1. Gehe auf [github.com](https://github.com) und erstelle ein neues Repository (z.B. `job-heroes`)
2. Lade alle Dateien aus diesem Ordner hoch (oder zippe sie und entpacke)
3. Gehe auf [vercel.com](https://vercel.com) → Mit GitHub anmelden
4. **Add New Project** → dein Repository auswählen
5. Bei Environment Variables eintragen:
   - `NEXT_PUBLIC_SUPABASE_URL` = `https://lugbspjuqoluwgwklbod.supabase.co`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = `sb_publishable_VNiYe9A-nuCgweKoMgFC7w_d-6ip8kf`
6. Deploy klicken

Nach 1–2 Minuten hast du eine Live-URL.

Danach kann ich alle weiteren Features (Profil, Filter, Admin, CV-Prüfung etc.) direkt in diesem Projekt bauen.
